# 中文使用说明

[English](USER_GUIDE.md)

## 安装准备
从 GitHub Releases 下载 Beta APK（目前使用 CI 临时 Debug 签名，后续更新可能需要卸载旧版），先在手机上启动 Shizuku，打开 Galaxy NR 工具并授权。成功时特权服务 UID 通常是 `2000`；无需额外安装终端工具。系统中文显示中文、其他语言默认英文；深浅色跟随系统。

保持手机解锁和屏幕亮起。确认使用的是美版 U/U1 的 S23 或更新机型，以及三星原生拨号器能够打开 `*#27663368378#`。只操作 SIM1。悬浮进度权限可选，不会截获下层点击。

## 第一步：只读检查
先点“5G 网络与能力检测”。它报告公开 Android 网络指标，**当前只有 4G/LTE 不代表 5G 被关闭**。任何公开接口都无法直接证明三星 NR PRUNE、GCF 白名单、SA permit list 或毫米波全部开启。

## 第二步：菜单探测
点击“探测六条菜单路径”。程序以截图 + 本机 OCR 识别 ServiceMode，并逐项检查路径，**不点击最终的设置选项**。结束后尝试切回应用；如果系统限制后台切换，可点前台通知回到结果。菜单缺失、多处匹配、OCR 无法可靠判断或焦点变化时自动停止。

## 第三步：必要时恢复
确认探测通过后，按需要选择“基础恢复（五项）”或“完整恢复（六项，含毫米波）”，阅读风险提示并明确授权。`ALL ENABLE (*)` 与 `SA/NSA ENABLE (*)` 是选中标记，避免反复点击；**第六项 REMOVE SA PERMIT LIST 是独立操作，不能因第五项已选中而跳过**。

真正完成全部恢复操作后会提示重启；仅探测成功或中途失败不出现重启权限。即使显示成功，也只能说明导航和点击已提交，并不能证明基带 NV 持久生效。

## 常见问题

| 问题 | 处理建议 |
|---|---|
| 重启后 Shizuku 断开 | 重新启动 Shizuku 并打开工具 |
| 暂时只有 4G | 检查覆盖、SIM、运营商配置、当前地区频段，不要直接认定 5G 被锁 |
| OCR 不识别菜单 | 先检查当前界面是否正确，提交脱敏日志及截图；程序不盲点 |
| 没有自动返回应用 | Android 可能限制后台 Activity 启动，点通知返回查看结果 |
| 覆盖安装失败 | 很可能前后安装包签名不同，目前 Beta 版本使用临时 Debug 签名；卸载旧测试版前保存日志 |
| 机型不支持 | 工程自动化仅支持已列出的美版 U/U1 型号，其他地区可使用只读诊断 |

## 日志与隐私
执行日志里可能出现 ServiceMode 原版英文菜单及旧版中文技术提示，这是调试文本，不会改变 UI 语言选项。截图是临时文件，不上传给应用作者；ML Kit SDK 自身可能采集性能指标，详见[隐私说明](../PRIVACY.zh-CN.md)。公开反馈前请去掉 IMEI、IMSI、手机号、地理位置和其他隐私。
